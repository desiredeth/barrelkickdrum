# BARREL KICK GENERATOR — Stage 1

1. Создайте пустой репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Откройте вкладку Actions -> "Build VST3 (Windows)" -> дождитесь зелёной галочки.
3. Скачайте артефакт BarrelKickGenerator-VST3-win64, распакуйте.
4. Скопируйте папку "BARREL KICK GENERATOR.vst3" в C:\Program Files\Common Files\VST3
5. FL Studio: Options -> Manage plugins -> Find plugins.
